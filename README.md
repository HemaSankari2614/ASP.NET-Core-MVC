# 💻 ASP.NET Core MVC

## 📌 About This Repository

This repository contains my learning and practice projects related to **ASP.NET Core MVC** using C# and .NET.

ASP.NET Core MVC is a web application framework based on the Model-View-Controller design pattern. It helps developers build structured, maintainable, and dynamic web applications.

## 🎯 Learning Objectives

- Understand the MVC architecture
- Build web applications using ASP.NET Core MVC
- Learn how Controllers, Models, and Views work together
- Perform CRUD operations
- Connect applications with SQL Server
- Understand routing and data passing
